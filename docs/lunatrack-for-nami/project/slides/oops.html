When a date showed the wrong day

A full moon on the 14th could show up as the 13th for some people. Nothing was broken in space; it was a timezone trap.

THE TRAP

A bare date with no time is read as midnight in London. If you live west of London, midnight there is still yesterday where you are, so the day slips back one.

THE FIX

Read every bare date as midnight where you are, not in London. One small helper, and the day stops drifting.

Little bugs like this are not about space being hard. They are about computers and clocks disagreeing about "when is today".

Computers treat a date-only text as UTC (London) midnight, then show it in the viewer's zone, so it can slip a day for anyone to the west. The fix parses it as local midnight. Ask Nami: if it is midnight in London, what day is it in New York? (Still the day before.)
