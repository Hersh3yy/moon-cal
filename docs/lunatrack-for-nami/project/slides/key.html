The secret pass that was on show

To ask the paid storyteller, Lunatrack needs a secret pass (a password just for machines). For a while that pass was printed right on the page, where anyone peeking could copy it.

THE SLIP

The pass sat in the page's text. A sneaky visitor could grab it and spend Hiren's €1 plan.

THE FIX

Now the errand boy keeps the pass hidden on the website's side. Your screen only ever sees the Moon answer, never the pass.

Bonus: the errand boy remembers the answer for 10 minutes, so a thousand people in Amsterdam cost just one ask instead of a thousand.

A key (API key) in public page text can be copied and misused; moving the call to the website's own side (a server route) keeps it secret, and caching the answer saves money. Hiren rates this low urgency because the plan is only €1 a month. Ask Nami: can you think of something you should never write where everyone can read it?
